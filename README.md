# Flower-Detitictions-
This project uses Deep Learning and Convolutional Neural Networks (CNNs) to automatically classify flower images into five categories: Daisy, Sunflower, Rose, Tulip, and Dandelion.

Developed using Python and TensorFlow/Keras, the model leverages image preprocessing and augmentation techniques to learn visual features and perform flower image classification.

🎯 Key Features

Flower image classification across five categories.

Image preprocessing and augmentation.

CNN model development and training.

Model evaluation on flower images.

Python

TensorFlow & Keras

OpenCV
